# Changes

## v1 — 2026-09-19

Initial delivery based on the supplied wooden food-shed reference.

- 2,952 triangles per open/closed static variant; one mesh and one material in each GLB.
- 1,556 separately allocated surface charts, approximately 222.09 px/m at 4096².
- AI-authored architecture and prop surface art; non-tiled face atlas, normal/ORM/emissive maps.
- Editable Blender reconstruction with door hinge pivots and a separate roof collection.
- UE 5.7 Editor import, master material, material instance and explicit collision/scale checks.
- Independent binary and geometry checks, source-to-GLB parity, actual mesh CPU previews.
