# H03-M1 / revision 1 — HOPPER 팔 연결 규약

이 문서는 **HOPPER 가상 게임 에셋용 자체 결합 규약**입니다. 실제 산업·제조 규격이 아니며, 하중과 공차를 인증하지 않습니다. 치수는 `reference/HOPPER_03_Legs_v4.glb`의 어깨 축과 림에서 측정했습니다. 본체 장갑이나 소켓을 깎거나 교체하지 않습니다.

## 1. 기준축과 원점

GLB의 미터 단위, 오른손 좌표계를 사용합니다. 본체 +Y가 위, +Z가 앞입니다. 원본 소켓 명칭은 R=+X, L=−X입니다.

개별 팔 모듈의 **원점은 기존 어깨 축 앞단 캡 평면의 중심**입니다. 모듈 +Z는 몸체에서 바깥으로 뻗는 장착 방향, +Y는 상단 기준 표시 방향, +X는 접선 방향입니다. 원점에서 몸체 쪽으로 슬리브가 46mm 들어갑니다. 기존 캡과 림이 들어갈 빈 공간을 두었으며, 막힌 원판을 소켓에 관통시킨 형태가 아닙니다.

표의 계산치는 원형 기준의 명목치입니다. 실제 저폴리 단면, 결합 위치와 콕핏 동작은 출력 GLB 표면 검사로 별도 확인했습니다. 모듈 +Y 쪽 황색 표시는 회전 방향을 맞추는 시각적 기준입니다. 6개 체결 위치와 서비스 표시는 게임 외관 표현이며 볼트 체결·분해 동작 애니메이션이 아닙니다.

## 3. 장착 방법 A — 원본 GLB 장면 좌표에 배치

가장 단순한 방법입니다. 원본 전체 모델과 팔의 공통 부모 transform을 동일하게 유지한 상태에서 팔 root에 아래 값을 적용합니다. 각 팔은 배율 1입니다. 쿼터니언 순서는 **x, y, z, w**입니다.

| 모듈 | 위치 x, y, z (m) | 회전 quaternion (xyzw) |
|---|---|---|
| R | 0.567286837, 1.571781957, −0.058715991 | 0, 0.707106781, 0, 0.707106781 |
| L | −0.567286837, 1.571781957, −0.058715991 | 0, −0.707106781, 0, 0.707106781 |

정밀값은 `socket_spec.json` → `sockets` → `L/R` → `scene_mount`에 있습니다. 여기서 말하는 장면 좌표는 이 원본 GLB 기준입니다. 엔진의 임의 월드 원점이나 화면 좌표가 아닙니다. 캐릭터 Actor에 공통 이동·회전·배율을 적용했다면 본체와 팔에 동일한 부모 변환이 적용되어야 합니다.

## 4. 장착 방법 B — 기존 Socket_L / Socket_R 노드의 자식으로 배치

**방법 A의 값을 소켓 노드 아래에 그대로 사용하지 마십시오.** 원본의 소켓 메시 정점은 저작 좌표에 있고, 소켓 노드 자체 translation은 0입니다. 또한 부모에게서 약 0.451661479의 배율을 상속합니다.

따라서 실제 `Socket_L` 또는 `Socket_R` 노드의 자식으로 붙일 때는 `under_source_socket_node`의 위치와 배율을 사용합니다.

| 모듈 | 자식 위치 x, y, z | 자식 회전 (xyzw) | 자식 scale |
|---|---|---|---|
| R | 1.256000042, 3.480000019, −0.129999997 | 0, 0.707106781, 0, 0.707106781 | 2.214047568 × 3축 |
| L | −1.256000042, 3.480000019, −0.129999997 | 0, −0.707106781, 0, 0.707106781 | 2.214047568 × 3축 |

이 scale은 팔의 실제 크기를 키우려는 것이 아니라 원본 부모의 배율을 상쇄하기 위한 값입니다. 실제 합성 world matrix가 방법 A와 일치하는지 자동 테스트했습니다. 두 방법 중 **하나만** 선택합니다. 임포터가 소켓 노드를 제거·병합하거나 좌표축을 변환한 경우, 이 노드 로컬값을 변환 없이 복사하지 말고 방법 A의 장면 행렬에 해당 엔진의 축 변환을 적용해야 합니다.

## 5. 팔 파일의 내부 구분

`Arm_L_M1_Root` / `Arm_R_M1_Root` 아래에 연결 컵, 어깨 피벗, 상완 프레임·외장, 팔꿈치 피벗, 전완 프레임·외장, 손목 피벗, `09_ToolPort`, 손 프레임·외장이 있습니다. ToolPort는 이번 모듈 내부의 향후 확장을 위한 기준점이며, 별도의 작동/전력/잠금 규격을 보장하지 않습니다.

새 팔 디자인도 동일한 root 원점·축·접합 치수를 유지하면 같은 장착 JSON을 사용할 수 있습니다. 외관의 크기, 이동 범위, 장갑 여유 공간은 새로운 형상마다 다시 확인해야 합니다. 현재 양팔 4,812삼각형을 사용할 때만 원본과의 총합이 29,870삼각형입니다.
