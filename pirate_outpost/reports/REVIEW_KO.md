# 제작·스크립트 검토 기록

검토 방식: **작성자 자체 검토**. 독립 검토 에이전트와 Blender/UE 에디터는 사용할 수 없었습니다.

## 수정한 문제

- 목재 원본 스와치의 검은 판재 이음선이 기둥에 반복되던 현상: 해당 선을 제거·보정하고 실제 GLB 렌더에서 재확인.
- 풀·잎의 끝점에서 삼각형 제거 후 남던 미사용 정점과 비정상 법선: 사용 정점만 재구성하는 처리 추가, 회귀 테스트 통과.
- 형틀 구멍 주변 일부 면의 winding/법선 방향 불일치: 면 방향 수정, 회귀 테스트 통과.
- 나무통 뚜껑보다 스테이브의 방사형 단면이 위에 보여 원형 조각처럼 보이던 현상: 원형 테두리로 잘라낸 실제 판재를 상단에 배치, 면적 검증 테스트 추가.
- 블렌더/렌더 스크립트와 JSON의 카메라 키 불일치: `position_m`/`target_m`으로 통일, 두 배치에 대한 계약 테스트 추가.
- UE 임포트 실패 후 미완료 에셋을 다음 실행이 성공으로 넘길 가능성: 완료 메타데이터 분리, 미완료 마무리 작업 재시도 및 원본 해시 확인 추가.
- 기존 사용자 데이터 훼손 방지: 새 Blender 씬 생성, 명시적인 파일 교체 옵션, UE 소유 태그 확인, 기본 덮어쓰기 금지, 레벨 자동 삭제·저장 금지.

## 제작상 선택

- 전체 시트 자동 image-to-3D 대신, 개별 구조를 명시적으로 모델링하는 결정론적 메시 생성기를 사용.
- 생성된 레퍼런스에서 재질 픽셀을 추출한 공용 아틀라스 사용. 독립적인 새 이미지 생성 텍스처는 아님.
- UV0는 중첩 재질 UV. 별도 고유 UV1을 제공하지 않아 정적 라이트맵 베이크는 추가 작업 필요.
- 빈 공간을 보존하기 위해 구조물 충돌 정책은 정적 complex로 지정. 물리 시뮬레이션용 충돌은 별도 제작 필요.
- 문·상자의 열린/닫힌 상태는 개별 정적 메시. 불꽃·천·배 역시 애니메이션 없음.
- UE 배치는 같은 StaticMesh 자산을 참조하는 개별 액터이며, HISM 자동 변환은 범위에 넣지 않음.

## 잔여 확인 사항

에디터 스크립트의 실제 실행·버전 차이·머티리얼 컴파일·충돌 생성은 아직 검증하지 못했습니다. Blender/UE 실행 성공이나 목표 게임의 프레임 성능을 주장하지 않습니다. 기본적인 소스/출력 검증을 통과한 전달본이며, 게임 프로젝트 안에서 테스트해야 합니다.

고유 UV1, LOD 체인, 상호작용/리깅, 완성된 실내 공간, GPU 인스턴스 묶기는 포함되지 않습니다. 일부 얇은 천·잎은 양면 표면이며, 모든 부품을 불리언 유니언한 폐합 솔리드 메시라고 주장하지 않습니다.
