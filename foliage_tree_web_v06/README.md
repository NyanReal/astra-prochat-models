# Foliage Tree — static web v06 / 자유시점

## 실행

`index.html`이 실제 실행 파일이다. 메시, 텍스처, 셰이더가 모두 포함된 독립 HTML이며 별도 서버·CDN·설치가 필요하지 않다. WebGL 2를 지원하는 브라우저에서 실행한다. 일반 스태틱 호스팅에는 이 파일 하나만 올려도 된다. 이 ZIP에는 공개 호스팅 주소가 포함되어 있지 않다.

카메라는 360° 오비트 자유시점이며 조명은 고정이다. 원래 구도를 유지하기 위해 직교 투영을 유지했다. 시점은 정면/좌우/뒤/위/아래로 바꿀 수 있고 지면 아래에서 올려볼 때는 바닥 표시를 숨긴다.

- 마우스 왼쪽 드래그 / 터치 한 손가락: 회전.
- 휠 / 두 손가락 핀치: 확대/축소.
- 우클릭·가운데 버튼·Shift+드래그 / 두 손가락 이동: 화면 이동.
- 더블클릭 / `F` / 시점 복귀: 카메라만 초기 구도로 복귀.
- `H`: UI 숨기기. PNG 저장은 실제 WebGL 캔버스 출력.

바람을 일시정지해도 카메라와 각 표시 모드는 계속 조작된다.

## v06 변경 범위

기존 v05의 줄기/잎 메시, 카드 피벗, UV, 이미지, 프록시 노멀, 베이크 색과 고정 광원을 **그대로 보존**했다. 현재 뷰의 Right/Up 축으로 쿼드 위치만 재구성한다. 카메라 축으로 셰이딩 노멀을 회전시키지 않는다. 표시되는 잎과 겹침은 시점에 따라 바뀌므로 화면 전체가 같은 색으로 보인다는 뜻은 아니다.

나무 전체 그라디언트는 여전히 없다. 카드의 in-plane 바람 회전을 먼저 계산한 뒤 카메라 평면으로 변환한다. 그림자 패스는 카메라에 따라 움직이지 않는 원래 방향의 카드 프록시를 사용한다. 이것은 표시 카드와 그림자 방향을 의도적으로 분리한 표현이다.

모든 카드는 3D 공간에 존재하나 기존 덩이 배치는 정면 중심으로 잡힌 그대로다. 옆에서 수관이 정면보다 좁게 보이는 것은 이번에 메시를 새로 부풀리지 않았기 때문이다.

## v05에서 바로잡은 사항 (이번에도 유지)

v04의 줄기는 2D Canvas 선/패턴이었고 실제 3D 줄기 메시나 UV가 없었다. 이번 버전은 이를 제거했다. 줄기·가지·뿌리는 하나로 연결된 실제 3D 삼각형 메시이고 잎과 같은 깊이 버퍼에서 렌더링한다. 별도의 2D 그림으로 줄기를 덧대지 않는다.

v04는 카드 크기를 UV 좌표에도 사용해 크기를 줄일 때 잎 패턴이 잘리는 구조였다. 이번에는 물리적 크기, 잎 마스크 UV, 프록시 셰이딩 노멀을 분리했다. 각 카드는 선택한 아틀라스 타일 전체를 읽는다.

- 기존 12개 구성에서 상단 909 / 1001 덩이 제거: 10개 유지.
- 남은 상부 중앙 덩이는 중심을 낮추고 세로 반경을 압축했다.
- 나무 전체 높이/위치 기반 그라디언트는 없다. 개별 덩이의 프록시 노멀 기반 명암만 유지했다.
- 카드 크기를 줄이고 덩이당 216개 표면 카드 + 72개 내부 카드로 채웠다. 총 2,880개 카드다.
- 입체 줄기를 곡선형 분기 골격의 부피 결합으로 만들었다. 가지 접합부도 메시로 연결되어 있다.
- 기존 대화에서 생성한 나무껍질 이미지를 줄기의 고유 UV 아틀라스에 베이크했다. 화면 위에 반복 패턴을 그리는 방식이 아니다.
- 바람은 카드 피벗 중심 회전 + 작은 덩이 단위 이동이다. 정지 상태의 명암은 바람과 분리했다.
- 실제 잎 마스크와 같은 바람 수식으로 3D 그림자 프록시를 렌더링한다. v06 표시 카드만 카메라를 추종한다.

## 주요 파일

`index.html`: 모든 데이터가 내장된 실제 정적 웹페이지.

`src/orbit-camera.js`: 마우스/터치 오비트·확대·이동 및 카메라 평면 계산.

`src/viewer.js`: 실행 중 사용하는 WebGL 2 셰이더 및 렌더링 코드. `src/page.html`은 UI 템플릿, `src/build_page.py`는 이 둘과 자산을 HTML 하나로 묶는다.

`src/build_assets.py`: 실제 메시/텍스처/GLB 재생성 스크립트. Python, numpy, scipy, scikit-image, Pillow, trimesh가 필요하다. 이들은 **재생성에만** 필요하고 웹 실행에는 필요하지 않다.

`assets/scene.json`: 웹에 내장된 것과 동일한 정점·인덱스·UV·피벗·프록시 노멀 데이터.

`assets/cards.json`, `assets/branch_skeleton.json`: 카드별 속성과 분기 골격.

`assets/trunk_basecolor.png`: 고유 UV에 베이크한 2K 줄기 베이스 컬러.

`assets/trunk_normal_gl.png`, `assets/trunk_normal_dx.png`: 베이스 컬러 명암에서 **추정한** 보조 노멀. 스캔/고해상도 조형에서 추출한 실측 노멀은 아니다. 웹은 GL 버전을 사용한다.

`assets/trunk_roughness.png`: 보조 러프니스. 웹은 스타일화한 무광 셰이딩을 사용하며 이 맵을 PBR 러프니스로 실시간 샘플링하지 않는다.

`assets/trunk_uv_layout.png`: 실제 UV 배치. 줄기 원통형 차트와 분기·끝부분을 위한 작은 보수 차트가 있다. 공유/겹침 UV 대신 독립 영역을 배정했으며 자동 언랩 결과다. 수작업 쿼드 리토폴로지라고 주장하지 않는다.

`assets/leaves_rgba.png`: 카드용 4×4 알파 아틀라스. 마스크는 벡터 기반으로 작성했으며 새로 이미지 생성했다고 주장하지 않는다.

`models/tree_v05.glb`: 웹과 같은 정지 상태 메시·UV·텍스처·잎 색을 내보낸 GLB. 바람 셰이더가 자동으로 다른 엔진에서 실행되는 파일은 아니다.

`ue5/PORTING.md`, `ue5/CardBillboardWind.hlsl`: 카메라 추종과 바람의 데이터 매핑 및 WPO 수식. 기존 `CardWind.hlsl`은 비빌보드 바람 참고용이다.

`validation/`: 실제 HTML을 Chromium에서 실행해 캡처한 PNG 및 실행 검사 결과. 별도 Python 그림 또는 생성 이미지가 아니다.

## 현재 통계와 범위

정확한 수치는 `assets/meta.json`에 있다. 줄기는 39,876 triangles, 잎은 5,760 triangles다. 이번 버전은 실제 웹 구현/외형 검증본이며, 다수 나무 배치를 위한 LOD와 최종 삼각형 최적화는 하지 않았다. 줄기 기하가 연결된 수밀 메시라는 검사와, UV/노멀/인덱스 유효성 검사를 수행한다.

GLB 재불러오기 및 브라우저 실행 검사는 포함하지만 Unreal Editor를 실행한 검증은 하지 않았다. UE5에서 머티리얼과 WPO를 다시 구성해야 한다. 웹에서는 빌보드 추종을 실행 검사했지만 정적 GLB가 UE에서 자동으로 빌보드가 되는 것은 아니다.

## 검증 및 재생성

```bash
python src/build_assets.py
python src/build_page.py
python -m unittest discover -s tests -p 'test_*.py' -v
# 검증 환경의 Chromium + SwiftShader가 X11 디스플레이를 요구하므로 Xvfb 사용
node --test tests/test_orbit.js
xvfb-run -a python tests/browser_check.py
xvfb-run -a python tests/browser_orbit_check.py
```

검증 환경은 브라우저 URL 탐색이 제한되어 있어 Playwright `page.set_content()`로 **배송되는 index.html 전체를 그대로** 실행했다. WebGL2 컨텍스트, 셰이더 컴파일/링크, 프레임 내 식생 표시, 상태 버튼, 사선 시점과 태블릿 크기를 점검한다. 이는 공개 사이트 배포 검증과 다르다.


## 이번 버전의 검증

`validation/freeview-report.json`에 실제 브라우저 검사 결과가 있다. 마우스 드래그·휠·팬·시점 복귀·카메라 프리셋·모드 버튼·PNG 저장·CDP 터치 입력·6개 시점 캡처를 확인한다.

GPU Transform Feedback으로 배송되는 실제 버텍스 셰이더의 2,880개 카드 출력을 읽어, 서로 다른 시점/바람 상태에서 프록시 노멀과 버텍스 컬러가 바뀌지 않는지, 카드 평면이 카메라를 향하는지 검사한다. 이 검사는 소프트웨어 렌더러 Chromium/SwiftShader에서 수행했으며 모바일 실기기 성능 보장은 아니다.

카메라의 극점 퇴화 방지를 위해 고도는 ±89.5°로 제한하고 방위각은 360° 순환한다. 렌더러에는 별도 외부 라이브러리나 CDN을 추가하지 않았다. 기존 메쉬 원본의 버전은 05이고 런타임 페이지 버전은 06이다.

입력 구현 참고: MDN Pointer Events / setPointerCapture / Pinch zoom gestures.

GPU 검증의 동기 readback에서는 파이프라인 stall 성능 경고가 기록될 수 있다. 이는 검사용 버퍼 읽기에서 발생한 것으로, 웹 렌더러 자체에는 이 readback 코드를 포함하지 않는다. `browser-report.json`의 일반 실행에서는 콘솔 경고/오류가 없었다.
