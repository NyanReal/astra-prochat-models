카메라 앵커 검사는 계산한 3D 위치를 다시 2D로 투영하는 수학적 왕복 검사입니다. 원본 일러스트와의 자동 유사도나 픽셀 일치 점수가 아닙니다.

## 실제 렌더의 범위

`previews/scene_camera.png`는 `data/scene.json`의 배치와 실제로 내보낸 메시 배열을 VTK로 렌더한 결과입니다. 그림자, SSAO와 BaseColor를 포함합니다. Blender/Unreal의 전체 PBR·톤매핑 결과와 같다고 표시하지 않았습니다.

각 개별 에셋 미리보기에도 실제 사용한 렌더 조건을 담은 JSON 기록을 함께 제공합니다. 생성형 컨셉 보드를 최종 렌더로 바꾸어 넣지 않았습니다.

## 아직 실행 검증하지 않은 항목

**Blender와 Unreal Editor 자체 실행은 하지 못했습니다.** 이 환경에 해당 실행 파일이 없었습니다. 따라서 아래 항목은 편집기 내 확인이 필요합니다.

- Blender GLB 임포터, 저장, Cycles/Eevee 렌더와 UI 문맥에서의 실제 실행.
- UE5 Interchange 임포트, 네이티브 머터리얼 컴파일, 편집기 레벨 생성·저장과 실제 조명·노출.
- 대상 PC의 성능, GPU 메모리, 드로콜 최적화, 충돌·내비게이션과 게임플레이.

Blender 스크립트는 임포트 경계 크기를 검증하고 대체 배열 로더를 제공합니다. UE 스크립트는 API 사전 점검과 실제 임포트 축 측정 과정을 포함합니다. 이러한 방어 코드는 편집기 실행을 완료했다는 뜻이 아닙니다.

사용자 환경에서 실행이 완료되면 각 스크립트가 별도의 `build_receipt.json`을 생성합니다. ZIP 안에 사전에 만들어 놓은 Blender/UE 실행 영수증은 없습니다.
