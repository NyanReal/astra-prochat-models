# UV와 텍스처

## 고유 면적 배분

각 원본 모델은 0–1 범위의 고유 UV 아틀라스를 사용합니다. 연속된 곡면은 하나의 UV 차트로 이어지고, 모서리가 갈라지는 면은 별도 차트로 나뉩니다. 한 차트 안에서도 UV 삼각형이 서로 겹치지 않는지 검사합니다. 반복 모델을 다른 위치에 놓을 때는 같은 메시·UV·텍스처를 공유합니다.

표면적과 지정한 목표 픽셀 밀도를 기준으로 차트 크기를 결정합니다. 삼각형의 UV 사용 면적을 실제 표면적으로 나눈 값에서 유효 texel density를 계산해 `data/assets.json`에 기록했습니다. 곡면의 펼침, 작은 차트의 최소 크기, 아틀라스 한계 때문에 목표값과 유효값은 다를 수 있습니다. 모델을 크게 또는 비균일하게 스케일하면 배치 후 월드 공간 밀도도 변합니다.

아틀라스 해상도는 128–2048 px 범위이며, 작은 검증용 모델을 제외한 주요 에셋은 512–2048 px를 사용합니다. 차트마다 3 px 여백을 두고 가장자리 색을 확장했습니다. GLB 샘플러는 Clamp이며 색상 텍스처를 타일 반복하지 않습니다.

`data/uv/<asset_id>.json`에는 각 차트의 원본 재질 종류, 픽셀 사각형, 표면적과 UV 사용 면적이 들어 있습니다. 다음 이미지가 실제 배치 예시입니다.

- `previews/UV_Truck_Abandoned.png`
- `previews/UV_Ground_Meadow_A.png`
- `previews/UV_Broadleaf_A.png`

## 이미지 생성 기반 재질

`source/generated_surfaces.png`는 이미지 생성으로 만든 4 × 4 재질 시트입니다. 콘크리트, 바위, 이끼, 금속, 목재, 흙과 식생 표면을 분리해 모델별 아틀라스로 배분했습니다. 큰 지면에서 소스의 작은 무늬가 과도하게 커 보이지 않도록 색·대비·주파수를 조정했습니다.

`source/generated_water_crop.png`는 다른 이미지 생성 결과에서 사용한 물 표면 부분입니다. 수면의 바탕색·명암에 사용하고, 물거품 윤곽은 `generated_foam_contours.json`으로 추출해 별도의 다각형 메시로 만들었습니다. 따라서 물거품 에셋에는 사각형 알파 카드의 외곽선이 없습니다.

글자와 표식은 정확한 문자열을 유지하도록 생성형 표면 위에 합성했습니다. 글꼴 파일은 포함하지 않습니다. 처리된 PNG를 `source/processed_surfaces/`에 고정 보관하므로 기본 재생성은 로컬 글꼴에 의존하지 않습니다.

## 맵 구성

| 파일 | 내용 | 색 공간 / 규약 |
|---|---|---|
| `*_BaseColor.png` | 색상 및 회화적 표면 표현 | sRGB |
| `*_Normal.png` | 이미지 명도에서 추정한 미세 표면 변화 | Linear, OpenGL tangent-space |
| `*_ORM.png` | R: AO, G: Roughness, B: Metallic | Linear |

AO 채널은 중립값으로 두고 접촉 음영은 렌더러에 맡겼습니다. Roughness와 Metallic은 재질 종류에 따른 표현용 추정값입니다. 측정 기반 스캔 재질은 아닙니다. UE 머터리얼 스크립트는 외부 Normal PNG의 Green 채널 반전을 설정하고, Blender는 OpenGL 규약 그대로 사용합니다.

수면의 색상 UV는 움직이지 않습니다. 제공하는 두 엔진용 머터리얼 스크립트는 월드 위치와 시간을 이용해 잔물결 노멀만 추가합니다. 실제 유체 시뮬레이션이나 물리적 반사 환경이 포함된 것은 아닙니다.

## 검증

패킹 사각형과 여백의 충돌, 0–1 범위 이탈, 실제 UV 삼각형의 면적 중복을 검사했습니다. 내장 GLB PNG와 외부 PNG의 픽셀도 비교했습니다. 최종 결과는 `validation/report.json`에 기록되어 있습니다.
