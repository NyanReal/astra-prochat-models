# UE5 실행 안내

## 대상과 준비

UE5.7의 공개 Editor Python API를 기준으로 작성했습니다. 실제 Unreal Editor 실행, 임포트 파이프라인과 머터리얼 컴파일은 이 제작 환경에서 검증하지 못했습니다. 다른 UE5 버전에서는 API 차이가 있을 수 있습니다.

Python Editor Script Plugin과 Editor Scripting Utilities를 활성화하고, glTF를 임포트하는 Interchange 기능을 준비하세요. 현재 작업 중인 레벨은 먼저 한 번 저장합니다. 실행 메뉴에서 `ue5/stillhere_environment.py`를 먼저 실행하면 읽기 전용 API 점검 결과를 로그에서 확인할 수 있습니다. 이 점검은 API 존재 여부만 확인하며 실제 임포트·셰이더 테스트를 대신하지 않습니다.

## 레벨 생성

편집기의 Python Script 실행 메뉴에서 `ue5/build_level.py`를 실행합니다. 현재 레벨 저장에 동의하는 확인 창이 나타납니다. 현재 레벨 저장이 실패하거나 취소되면 새 레벨을 만들지 않습니다.

그다음 에셋 임포트와 머터리얼 준비를 수행하고, 별도의 `/Game/StillHere_D3/Maps/L_StillHere_D3` 레벨을 만듭니다. 같은 이름이 있으면 날짜와 시간이 붙은 새 맵을 만듭니다. 기존 레벨의 액터를 지우거나 기존 맵을 덮어쓰는 코드는 없습니다.

기본 Content 구조:

```text
/Game/StillHere_D3/Imported/<asset_id>/   GLB 임포트 결과
/Game/StillHere_D3/Textures/              명시적으로 설정한 외부 PNG 텍스처
/Game/StillHere_D3/Materials/             네이티브 머터리얼
/Game/StillHere_D3/Maps/                  생성 레벨
```

GLB 임포트 과정에서 엔진이 만든 기본 머터리얼·텍스처가 `Imported` 아래에 남을 수 있습니다. 최종 슬롯에는 별도로 구성한 네이티브 머터리얼을 연결합니다. 임포트 결과의 실제 객체 경로를 사용하므로 파일 이름이 곧 Unreal 객체 이름이라고 가정하지 않습니다.

## 축·단위 보정

`Axis_Probe_X/Y/Z.glb`는 각각 원점을 기준으로 1 m 떨어진 작은 메시입니다. 이를 먼저 임포트한 뒤 StaticMesh 경계의 중심을 읽어 실제 축과 단위를 측정합니다. 원본 장면은 미터·Z-up 좌표이고, UE 레벨은 센티미터와 X/-Y/Z 매핑으로 통일합니다.

측정한 임포트 축에 맞춰 회전과 비균일 크기까지 보정합니다. 임포터가 피벗을 자동으로 중앙에 옮겨 측정이 불가능한 경우에는 조용히 잘못 배치하지 않고 중단합니다. 기본 glTF 임포트 변환을 사용하고 피벗 재중앙정렬 설정을 확인하세요. 검증용 3개 모델은 레벨에 배치하지 않습니다.

## 공유와 수정

배치 오브젝트는 별도의 편집 가능한 StaticMeshActor이며, 반복 모델들은 같은 StaticMesh 에셋을 참조합니다. 자동 HISM 변환이나 자동 Nanite 활성화는 하지 않습니다. 이 패키지의 수치는 메시·인스턴스 수이며, 특정 PC의 프레임 성능 보장은 아닙니다.

기본 `REIMPORT_ASSETS=False`, `REBUILD_MATERIALS=False`는 기존 임포트 에셋과 수동 변경을 보존하기 위한 설정입니다. 원본 GLB를 변경한 뒤 갱신할 때는 의도적으로 옵션을 켜세요. 원본 해시가 바뀌었는데 기존 메시를 보존하면 경고를 남깁니다. 이미 다른 재질을 수동 할당한 슬롯도 기본적으로 보존하도록 했습니다.

## 카메라·조명·물

`SH_Camera_Reference`는 직교 카메라이며 가로 3,600 cm, 화면비 3:2입니다. 스크립트는 이 카메라를 선택하고 가능한 경우 파일럿 시점으로 전환합니다. 조명과 노출은 주간 장면의 시작값이며, VTK 미리보기와 엔진의 톤매핑·그림자가 픽셀 단위로 같지는 않습니다.

수면은 불투명 스타일 재질입니다. 고유 색상 UV를 스크롤하지 않고 월드 좌표 기반 노멀만 애니메이션합니다. 폭포와 물거품은 별도 메시입니다. 플레이어, 리깅, 내비게이션과 게임플레이용 충돌 검수는 포함하지 않습니다.

## 결과 기록

완료 시 프로젝트의 `Saved/StillHere_D3/build_receipt.json`에 엔진 버전, 생성 레벨 경로, 실제 StaticMesh 경로, 축 보정값, 배치 수와 경고를 저장합니다. 이 파일은 사용자 UE 편집기에서 실제 실행이 완료되었을 때만 생성됩니다. 문제가 발생하면 먼저 Output Log의 첫 오류와 해당 실행 기록을 확인하세요.
