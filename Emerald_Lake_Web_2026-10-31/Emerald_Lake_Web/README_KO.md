# Emerald Lake — 숲속 낚시터

제공된 레퍼런스의 청록빛 물, 짙은 침엽수, 밝은 흙길, 낚시 데크와 보급 야영지를 바탕으로 제작한 스타일라이즈드 3D 웹 장면입니다. 3D 지형과 소품은 JavaScript에서 메시로 생성하며, 이미지 생성으로 제작한 재질 아틀라스를 실제 UV에 적용합니다. 기본 구도는 위에서 내려다보는 직교 카메라입니다.

## 바로 실행하기

ZIP을 먼저 **전체 압축 해제**하세요.

### Windows

Python 3가 설치되어 있다면 `START_WINDOWS.bat`를 실행합니다. 기본 브라우저에서 `http://127.0.0.1:8000/`이 열립니다.

### macOS / Linux

프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
python3 serve.py
```

Windows 터미널에서는 `python serve.py` 또는 `py -3 serve.py`도 사용할 수 있습니다. 포트가 사용 중이면 `python3 serve.py --port 8001`로 실행합니다. 서버를 종료하려면 터미널에서 Ctrl+C를 누릅니다. 서버는 내 컴퓨터의 127.0.0.1에만 연결합니다.

이 프로젝트는 ES 모듈을 사용하므로 HTML 파일을 더블클릭하는 `file://` 방식 대신 위 로컬 서버를 사용합니다. 실행에 npm 설치나 빌드 과정은 필요하지 않습니다. 렌더링 라이브러리와 모든 텍스처가 포함되어 있어 외부 CDN과 외부 폰트를 요청하지 않습니다.

| 확대·축소 | 마우스 휠 / 두 손가락 벌리기·모으기 |
| 화면 이동 | 마우스 오른쪽 버튼 드래그 / 두 손가락 이동 |
| 지정된 장소로 이동 | 전체 풍경 / 낚시 데크 / 작은 폭포 / 보급 야영지 버튼 |
| 물결과 바람 일시정지 | 하단 일시정지 버튼 / Space |
| 처음 시점으로 돌아가기 | 하단 되돌리기 버튼 / R |
| UI 숨기기·표시 | 설정의 화면 가득 감상 / H |
| UI 다시 표시 | 화면 하단 표시 버튼 / Escape |
| 원본 비교 | 오른쪽 위 이미지 아이콘 |
| 햇살·화질·자동 회전 | 오른쪽 위 설정 아이콘 |

실시간 화면에는 WebGL 2가 필요합니다. WebGL을 만들 수 없는 환경에서는 **같은 모델을 별도 렌더러로 렌더링한 정지 미리보기** 네 장을 표시하며, 상단에 `RENDER PREVIEW`를 명시합니다. 이 경우 시점 버튼은 이미지 선택으로 동작하고 실시간 햇살·화질·회전 조작은 제공되지 않습니다.

## 장면 구성

- 불규칙한 호수 지형, 흙길, 절벽과 이끼 바위, 작은 섬
- 침엽수 63그루와 반복 배치된 잎·풀·고사리·야생화
- 나무 낚시 데크 두 곳, 디딤 계단, 지지 기둥과 작은 다리
- 낚싯대·낚싯줄·찌·접이식 의자·보급 상자
- 작은 적재 트럭, 줄무늬 차양, 목재 울타리와 조명 표지
- 깊이별 청록색 수면, 물속 바닥 무늬, 잔물결과 세 구간의 작은 폭포
- 움직이는 물고기·찌·부유 입자와 식생의 가벼운 바람

반복 식생과 바위는 인스턴싱하고, 정적인 소품은 재질별로 합쳐 그리기 호출을 줄였습니다. 현재 모델 수와 삼각형 수는 `qa/offline/render-report.json`에 기록되어 있습니다. 실제 프레임 속도는 기기와 브라우저에 따라 달라집니다.

## 트럭·물가·계곡 수정본

- 트럭: 모서리를 다듬은 차체, 분할 앞유리와 창틀, 와이퍼·미러·손잡이, 라이트·그릴·범퍼, 타이어 트레드와 휠 볼트, 목재 적재함과 고정 끈을 추가했습니다.
- 물가: 바위의 물쪽 면과 섬 바깥에 폭이 달라지는 흰 포말을 배치했습니다. 끊어진 호와 잔물결이 겹치며 가장자리는 알파 텍스처로 부드럽게 풀립니다.
- 계곡: 연속된 수면이 굴곡 있는 낙차를 따라 내려옵니다. 수중 바닥 무늬, 방향성 물살, 낙차의 밝은 물줄기와 하단 포말을 셰이더와 실제 메시로 표현합니다.

세 부분의 실제 모델 근접 렌더는 `qa/revision-02/truck_detail.jpg`, `stream_detail.jpg`, `shore_detail.jpg`에 들어 있습니다. 브라우저의 실시간 3D와 별도로 생성한 확인용 정지 렌더입니다.

## 수정하는 법

카메라의 기본 구도와 네 가지 시점은 `main.js`의 `views`에서 조절합니다. 호수 형태와 수위는 `world.js`에서 변경합니다. 서로 다른 구성 요소가 같은 윤곽과 높이 함수를 사용하므로, 한 곳에서 수정하면 지형과 식생 배치가 함께 변합니다. 소품은 `props.js`의 개별 생성 함수를 통해 크기·위치·색을 바꿀 수 있습니다.

재질 아틀라스는 3열 × 2행입니다. 위쪽부터 순서대로 흙길 / 목재 / 석회암, 풀과 이끼 / 올리브색 금속 / 물속 바닥이며, 실행 시 각 타일을 분리해 사용합니다. 바늘잎 등 일부 식생 텍스처는 코드에서 CanvasTexture로 생성합니다.

## 정적 호스팅

`dist/` 폴더 내용 전체를 정적 호스팅의 게시 폴더로 올립니다. 별도 서버 코드나 데이터베이스가 필요하지 않습니다. JavaScript의 MIME 타입이 올바르게 제공되어야 하며 모든 상대 경로를 유지해야 합니다. 개별 파일은 25 MiB 미만입니다.

## 검증 범위

JavaScript 구문, 모든 로컬 모듈·파일 참조, 호수 윤곽의 연속성, 모델 좌표·인스턴스 행렬의 유한값, 네 장의 렌더 이미지, ZIP 무결성을 확인했습니다. 실제 모델은 별도의 EGL/OpenGL 렌더러로 출력해 구도와 지오메트리를 확인했습니다.

작업 환경의 미리보기 브라우저는 그래픽 장치가 `Disabled`로 보고되어 WebGL 컨텍스트를 생성할 수 없었습니다. 따라서 **해당 브라우저에서 실시간 3D 렌더링과 회전·물결 동작까지 검증했다고 주장하지 않습니다.** 브라우저에서는 정지 미리보기 모드와 페이지 조작을 확인했습니다. 별도 렌더러의 조명 근사와 생략된 작은 요소는 `qa/offline-report.md`에 명시했습니다.

원본 이미지의 색감·요소를 바탕으로 구성한 3D 재해석이며, 원본과 픽셀 단위로 동일한 재구성은 아닙니다.
